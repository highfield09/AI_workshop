# Before class · TA rehearsal

Every TA should run all six notebooks once in a fresh, separate Codespace before
supporting participants. This is a preparation checklist, not a record of completion.

- Use the planned classroom machine size (16 GB RAM for Workbook 6).
- Follow Workbook 1's master setup. Confirm the local GLM-OCR model, first ten
  receipt images and reference CSV are ready; keep the exercise at five receipts.
- Check the .venv kernel, worksheet submission, pink dropdowns and mini quizzes.
- Rehearse Workbook 3's model selection and OpenRouter key setup using your own
  account. Check the vision attachment and Activity page; never ask students to
  paste keys into chat or share screenshots showing keys. Respect their budget.
- Run both debugging tasks in Workbook 4, including Agent-mode edit review.
- Open Workbook 5's catalogue through Live Server and verify the new data paths.
- Run the five-receipt OCR exercise, inspect spreadsheet tabs, then check the chart.
- Practise explaining Save versus Submit & save: Auto Save may save notebook
  edits but does not submit widget answers. Workbook 4 has no answer JSON form.
- Know how to restart the kernel, rerun setup and confirm a Saved message.
- Note interface changes or blockers for the trainer before class. Support
  account/model setup individually without exposing credentials.
