# Workbook 3 · Your chosen image

Save a public JPG/PNG image you have permission to use, then drag the downloaded
file from your laptop into this folder in the Codespace Explorer. Avoid private documents or images
containing personal data, passwords or API keys.

Next drag the saved file **from Explorer into Copilot Chat** and confirm an
attachment chip appears. A file saved in this folder is not automatically sent
to the model. Inspect the description, then check input tokens, output tokens
and cost in OpenRouter Activity. Observation only—no written submission.

Your own images are Git-ignored. This README and the supplied
`Screenshot 2026-02-23 145127.png` are distributed with Workbook 3.
