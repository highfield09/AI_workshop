# Apparel asset generation notes

These six base images and twelve colour siblings were generated with the built-in image-generation tool.

## Shared prompt

> Use case: stylized-concept. Asset type: shopping catalogue product image. Style: crisp 32-bit pixel art with deliberate block pixels and a clean game-inventory icon look. Show one front-facing item, centred at a consistent catalogue scale with generous padding, on a genuinely transparent background. Use simple readable highlights. Include no person, mannequin, hanger, text, logo, trademark, border, or watermark.
