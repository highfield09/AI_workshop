# Your workshop space

- **notebooks/** — open Workbook 1 first; follow the six lessons in order.
- **data/** — inspect the supplied images and tables. Change only the exercise
  data a workbook specifically asks you to repair; preserve OCR originals.
- **tasks/** — create your own scripts and find your saved worksheet answers.
- **outputs/** — find your HTML catalogue, Excel spreadsheet and other results.
- **Resources/** — optional reading.

The supplied OCR model is in `tasks/06_receipt_ocr/model/`. Use it as an input;
do not edit its binary file. Student-created scripts and outputs stay local and
Git-ignored. File paths printed in the workbooks are relative to the repository
root unless explicitly described otherwise.
