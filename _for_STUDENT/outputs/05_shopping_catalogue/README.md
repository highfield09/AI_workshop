# Workbook 5 · Your shopping catalogue

Create `catalogue.html` here. Ask Copilot Chat in **Ask** mode with model **Auto** to return the code, then paste it into the file yourself.

Right-click inside the HTML editor and choose **Open with Live Server**. If a browser tab does not open, use the **Ports** tab to open forwarded port **5500**, then visit `/outputs/05_shopping_catalogue/catalogue.html` on that forwarded site. Keep the port private.

Load the CSV from `../../data/notebook1/products.csv` and images from `../../data/notebook1/`. The data folder keeps its original name so existing input links still work.

The source contains two deliberate defects. Keep every product visible, provide a missing-image fallback, and inspect and repair the source in your next iteration. Then practise choosing useful fields and expressing a clear sort order.

HTML files here are Git-ignored and belong to this Codespace only.
